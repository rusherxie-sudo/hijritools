# HijriTools 工具补全开发计划

> 目标：把工具站补全到"每个分类都饱满"。原则：**只做纯计算 / 查表 / 客户端库的零验证风险工具**（A 级），破坏"纯静态无外部数据"铁律的单独立项。
> 现状：33 个已上线工具。分类失衡——娱乐仅 1 个，日期缺"时间/工时"，其余较全。
> 本计划共 **23 个纯计算新工具**（分 5 批）+ **3 个特殊立项**（需前置条件）。全部落地后 33 → 56，分类恢复均衡。

## 通用前置约定（每个工具都遵守）

1. **无需新分类**——22 个工具全部落入现有 6 分类。`categoryNamesAr` 不用改。
2. **免责声明变体**：
   - 娱乐类（love-match / zodiac / chinese-zodiac）→ `variant="entertainment"`
   - 健康类（sleep / heart-rate / macros）→ `variant="health"`
   - 其余计算类 → `variant="calc"`
3. **TDD 铁律**：有纯函数的（算法/查表）先写 `tests/<tool>.test.js` 确认 RED，再实现 `src/lib/<tool>.js`。纯客户端交互（抛硬币/密码/打字）无纯函数部分可豁免，但可测的辅助函数仍要测。
4. **护城河标记 🌙**：能出伊历版的工具（date-add / weekday）双历输出，是竞品做不出的差异点。
5. **SEO**：h1/描述/FAQ 落主关键词；`related` ≥3 内链；数字套 `.num`。
6. **开发流程**：`tools.js` 加元数据 → TDD → `src/pages/<slug>/index.astro`（ToolLayout + 底部 module script）→ `npm run build` 验证。

# 批次 A — 娱乐补全（最优先，5 个）✅ 已上线 2026-07-01

> 娱乐类是最大空洞（只有 1 个），纯客户端零风险、最易传播。全挂 `entertainment` 免责。
> **状态：5 个全部完成、测试 +27 全绿、已部署 hijritools.com、阿语审校通过（生肖「羊」已由 الماعز 改为 الخروف）。娱乐类 1 → 6。**

### A1. 姓名配对 / 爱情计算 `love-match`
- **阿语**：حاسبة الحب · توافق الأسماء ｜图标 💕
- **核心**：`loveScore(nameA, nameB)` → 0–100 百分比。**必须确定性**（同名同结果，非随机）——用字母计数/FLAMES 类算法对两个名字做哈希。娱乐性质。
- **TDD**：同输入恒定；对称或非对称需锁定；越界名（空）报错。
- **SEO**：`حاسبة الحب`、`توافق الأسماء`、`نسبة الحب بين اسمين`
- **风险**：entertainment 免责必挂（"للتسلية فقط"）。

### A2. 星座查询 `zodiac`
- **阿语**：برجك حسب تاريخ الميلاد ｜图标 ♈
- **核心**：`zodiacSign(month, day)` → 12 星座之一。数据表 `src/data/zodiac.js`（12 星座 + 日期边界 + 阿语名 + 简短特质文案）。纯查表。
- **TDD**：边界日期（如 3/21 白羊起点）；每月两侧正确归属。
- **SEO**：`ما هو برجي`、`الأبراج حسب تاريخ الميلاد`、`برجي حسب يوم ميلادي`
- **风险**：占卜运势内容不做（只做"你是什么星座"查表 + 中性性格描述），entertainment 免责。

### A3. 中国生肖 `chinese-zodiac`
- **阿语**：برجك الصيني حسب سنة الميلاد ｜图标 🐉
- **核心**：`chineseZodiac(gregYear)` → 12 生肖之一（`year % 12` 映射）。数据 `src/data/chinese-zodiac.js`（12 生肖阿语名 + 特质）。与性别预测表同源（清宫/中国民俗主题）。
- **TDD**：已知年份锁定（2024=龙、2025=蛇…）；跨世纪年份正确。
- **SEO**：`البرج الصيني`、`الأبراج الصينية حسب سنة الميلاد`
- **风险**：entertainment 免责。

### A4. 随机抽签 / 转盘 `random-picker`
- **阿语**：القرعة · الاختيار العشوائي ｜图标 🎯
- **核心**：粘贴名单（每行一个）→ 随机抽一个 / 打乱顺序 / 转盘动画。纯客户端 `Math.random`。
- **可测辅助**：`parseNames(text)`（去空行/去重可选）可单测；抽取本身随机不测。
- **SEO**：`القرعة`、`اختيار اسم عشوائي`、`عجلة الحظ`
- **风险**：低。无免责或轻提示。

### A5. 抛硬币 · 掷骰子 `coin-dice`
- **阿语**：رمي العملة والنرد ｜图标 🪙
- **核心**：抛硬币（صورة/كتابة）+ 掷 1–6 骰子（可选骰子数）。纯客户端动画。
- **SEO**：`رمي العملة`、`حجر نرد`、`قرعة عشوائية`
- **风险**：低。

# 批次 B — 日期/时间补全（4 个，含 2 个护城河）

### B1. 工时 / 时间间隔计算器 `time-calc`
- **阿语**：حاسبة الساعات · الوقت بين وقتين ｜图标 ⏱️
- **核心**：`timeDiff(t1, t2)` 两个 HH:MM 间隔（小时/分钟，处理跨午夜）；`addTime(t, h, m)` 加减时间。纯函数。
- **TDD**：09:00→17:30 = 8h30m；23:00→01:00 跨午夜 = 2h；加减进位。
- **SEO**：`حساب الساعات بين وقتين`、`حاسبة ساعات العمل`、`كم ساعة بين وقتين`
- **风险**：低。打工族高频。

### B2. 日期加减 `date-add` 🌙
- **阿语**：إضافة أيام إلى تاريخ · طرح أيام ｜图标 ➕
- **核心**：`addDays(date, n)` → 目标日期，**双历输出**（公历+伊历）。复用 `date-utils.addDays` + `hijri.js`。护城河：伊历版竞品少。
- **TDD**：2026-01-01 + 100 天 = 2026-04-11；负数（减天数）；跨闰年；伊历换算正确。
- **SEO**：`إضافة أيام إلى تاريخ`、`كم التاريخ بعد كذا يوم`、`حساب تاريخ بعد عدد أيام`
- **风险**：低。复用现成 lib。

### B3. 星期几查询 `weekday` 🌙
- **阿语**：أي يوم كان هذا التاريخ ｜图标 📆
- **核心**：`weekdayOf(date)` → 阿语星期名。支持公历/伊历双输入。复用 `hijri.js` 的 `WEEKDAYS_AR`。
- **TDD**：已知日期锚点（如某伊历新年是星期几）；公历/伊历两路径一致。
- **SEO**：`أي يوم كان تاريخ ميلادي`、`ما هو يوم تاريخ`、`اليوم من التاريخ`
- **风险**：低。护城河（伊历某日星期几）。

### B4. 时区转换 `timezone`
- **阿语**：تحويل التوقيت بين المدن ｜图标 🌍
- **核心**：`convertTz(time, fromOffset, toOffset)`。数据 `src/data/timezones.js`（海湾 + 主要城市固定 UTC 偏移）。
- **TDD**：利雅得(UTC+3)→伦敦(UTC+0) 时差 3h；跨日进位。
- **SEO**：`تحويل التوقيت`、`الفرق بين توقيت الرياض و`、`كم الساعة في`
- **风险**：中——**部分国家有夏令时**（欧美），海湾无 DST。首版用固定偏移 + FAQ 注明 DST 例外，或只做无 DST 的海湾/亚洲城市。**实现前确认范围**。

# 批次 C — 财务补全（4 个，海湾刚需）

### C1. 黄金计算器 `gold`
- **阿语**：حاسبة الذهب · تحويل عيار الذهب ｜图标 🥇
- **核心**：`goldValue(weight, karat, pricePerGram24)`——克拉纯度换算（24k=1、21k=21/24、18k=18/24…）× 单价 × 重量。**单价用户输入**（不抓实时金价 → 保持纯静态）。数据：克拉纯度表。
- **TDD**：10g 21k，24k 单价 300 → 值 = 10×(21/24)×300；克拉换算表正确。
- **SEO**：`حاسبة الذهب`、`تحويل عيار الذهب`、`حساب سعر الذهب حسب الوزن`
- **风险**：低。海湾超高频。（注：实时金价版是另一回事——见特殊立项思路，但本工具用户自填价即可，纯静态。）

### C2. 复利 / 储蓄计算器 `compound-interest`
- **阿语**：حاسبة الفائدة المركبة · الادخار ｜图标 📈
- **核心**：`A = P(1 + r/n)^(nt)`，输出终值 + 累计收益。纯公式。
- **TDD**：本金 1000、年利 10%、10 年、年复利 → 已知值锁定；月复利 n=12。
- **SEO**：`الفائدة المركبة`、`حاسبة الادخار`、`حساب العائد على الاستثمار`
- **风险**：低。配退休工具。

### C3. 通用贷款分期 `loan`
- **阿语**：حاسبة القرض · التقسيط الشهري ｜图标 🏦
- **核心**：月供 = `P·r·(1+r)^n / ((1+r)^n − 1)`。**复用 `mortgage` 的公式 lib**（房贷是地产专用，本工具通用车贷/个人贷）。输出月供 + 总额 + 总利息 + 摊还表(可选)。
- **TDD**：复用 mortgage 测试锚点；零利率退化为 P/n。
- **SEO**：`حاسبة القرض`、`حساب القسط الشهري`、`حاسبة التقسيط`
- **风险**：低。复用现成公式。

### C4. 利润率 / 加价计算器 `profit-margin`
- **阿语**：حاسبة هامش الربح والتسعير ｜图标 💹
- **核心**：`margin = (price−cost)/price`、`markup = (price−cost)/cost`。给成本+售价算利润率，或给成本+目标利润率算售价。纯公式。
- **TDD**：成本 80 售价 100 → margin 20%、markup 25%；反算售价。
- **SEO**：`هامش الربح`、`حساب نسبة الربح`、`حاسبة التسعير`
- **风险**：低。商户向。

# 批次 D — 健康 + 教育补全（5 个）

### D1. 睡眠周期计算器 `sleep`
- **阿语**：حاسبة النوم · دورات النوم ｜图标 😴
- **核心**：按 90 分钟周期 + 14 分钟入睡。给起床时间倒推几个入睡点；或给入睡时间正推几个起床点。纯时间计算。
- **TDD**：起床 06:00、6 个周期 → 入睡 21:06；周期数与时长对应。
- **SEO**：`حاسبة النوم`、`أفضل وقت للنوم`、`متى أنام لأستيقظ الساعة`
- **风险**：health 免责。爆款。

### D2. 目标心率 `heart-rate`
- **阿语**：معدل ضربات القلب المستهدف ｜图标 ❤️
- **核心**：最大心率 = `220 − age`；区间 = 各百分比（热身 50–60%、燃脂 60–70%、有氧 70–80%…）。可选 Karvonen（含静息心率）。
- **TDD**：age 30 → maxHR 190；各区间边界；Karvonen 公式。
- **SEO**：`معدل ضربات القلب المستهدف`、`نبضات القلب الطبيعية حسب العمر`
- **风险**：health 免责。配卡路里工具。

### D3. 宏量营养 / 蛋白质 `macros`
- **阿语**：حاسبة الماكروز وتوزيع البروتين ｜图标 🥗
- **核心**：从 TDEE + 目标（增肌/减脂/维持）按比例分蛋白/碳水/脂肪克数。**复用 `calories` 的 TDEE lib**。
- **TDD**：TDEE 2000、维持比例 → 蛋白/碳水/脂肪克数（4/4/9 kcal/g）;和为 TDEE。
- **SEO**：`حاسبة الماكروز`、`احتياج البروتين اليومي`、`توزيع الماكروز`
- **风险**：health 免责。

### D4. 期末/及格分计算器 `final-grade`
- **阿语**：كم أحتاج في النهائي للنجاح ｜图标 🎯
- **核心**：`needed = (target − current×(1−w)) / w`——"期末占 w%，想拿 target，现在有 current，期末要考多少"。纯公式。
- **TDD**：期末占 40%、目标 60、现有 70 → 期末需 45；无法达成时提示（>100）。
- **SEO**：`كم أحتاج في الاختبار النهائي`、`حساب الدرجة المطلوبة للنجاح`
- **风险**：低。学生刚需。

### D5. 学期平均分 `semester-average`
- **阿语**：حاسبة المعدل الفصلي ｜图标 📊
- **核心**：加权平均（分数×学分/权重）。**复用 `weighted` / `gpa` lib**。
- **TDD**：复用现成加权测试锚点。
- **SEO**：`حاسبة المعدل الفصلي`、`حساب معدل الفصل`
- **风险**：低。复用现成。

# 批次 E — 工具补全（4 个）

### E1. 阿拉伯↔西文数字转换 `arabic-numerals`
- **阿语**：تحويل الأرقام الهندية والعربية ｜图标 🔢
- **核心**：`٠١٢٣٤٥٦٧٨٩` ↔ `0123456789`（可含波斯 `۰۱۲۳`）双向。纯字符串映射。
- **TDD**：双向转换；混合文本只转数字；往返守恒。
- **SEO**：`تحويل الأرقام الهندية إلى عربية`、`تحويل الأرقام العربية والإنجليزية`
- **风险**：低。阿语刚需（含 tafqit 姐妹）。

### E2. 密码生成器 `password`
- **阿语**：مولّد كلمات المرور القوية ｜图标 🔐
- **核心**：客户端 `crypto.getRandomValues`，选项（长度、大小写、数字、符号）。
- **可测辅助**：`buildCharset(options)` 可单测；生成随机不测。
- **SEO**：`مولد كلمات المرور`、`إنشاء كلمة مرور قوية`
- **风险**：低。纯客户端（不上传）。

### E3. 文本处理工具 `text-tools`
- **阿语**：أدوات النص: عكس · إزالة التكرار · تكبير/تصغير ｜图标 ✂️
- **核心**：反转文本、去重复行、大小写转换、去阿语标符(تشكيل)。纯函数（与 wordcount 互补，不重叠计数）。
- **TDD**：各变换正确；去重保序；去标符正确。
- **SEO**：`عكس النص`、`إزالة الأسطر المكررة`、`إزالة التشكيل`
- **风险**：低。

### E4. 打字速度测试 `typing-test`
- **阿语**：اختبار سرعة الكتابة ｜图标 ⌨️
- **核心**：给一段阿语文本，计时输入 → WPM = `(字符数/5)/分钟` + 准确率。交互为主。
- **可测辅助**：`calcWpm(chars, seconds)`、`accuracy(typed, target)` 可单测。
- **SEO**：`اختبار سرعة الكتابة`、`قياس سرعة الطباعة`
- **风险**：低。趣味互动。

# 特殊立项（需前置条件，暂不进批次）

> 这些流量很大，但破坏"纯静态 / 零验证风险"铁律，需先解决数据源或权威校验才能做。

### S1. 离职补偿计算器 `end-of-service`（C 级）
- **阿语**：حاسبة نهاية الخدمة
- **卡点**：沙特劳动法公式（前 5 年半月薪/年、5 年后满月薪/年、辞职 vs 解雇规则不同）需**权威法条来源 + 人工核实**。海湾各国不同。
- **前置**：沙特先行，引 نظام العمل 官方条文，data/lib 分离（法规变只改 data）。搜索需求极高（حاسبة الضمان 18K/月），值得优先解决前置。

### S2. 汇率转换 `currency`（破纯静态）
- **阿语**：محوّل العملات
- **卡点**：需实时汇率 → CI 流程定时拉取写入 data，或客户端调 API（引入第三方往返）。
- **前置**：搭一个每日汇率 CI（类似天课金价流程）。

### S3. 祷告时间 `prayer-times`（破纯静态 + 敏感）
- **阿语**：مواقيت الصلاة
- **卡点**：需天文计算库或 API + 按城市 + 教法计算方法（各地不同）+ 宗教准确性校验。
- **前置**：选定权威算法源（如 Umm al-Qura 官方方法）+ 阿语审校。

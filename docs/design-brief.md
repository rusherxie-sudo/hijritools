# HijriTools 设计需求文档

## 一、项目背景

阿拉伯语（RTL）在线工具站，面向海湾六国（沙特、阿联酋、卡塔尔、科威特、巴林、阿曼）用户，提供免费的日期换算、健康、财务、教育类计算工具。纯内容型网站，无注册/登录，所有计算在浏览器端完成，不收集用户数据。

---

## 二、技术架构约束（设计必须适配）

- **框架**：Astro SSG（纯静态 HTML 输出），无服务端渲染
- **语言方向**：**全站 RTL**（从右向左），`<html lang="ar" dir="rtl">`
- **字体**：阿拉伯字体（Tajawal），西文数字/计算结果需单独处理（`dir: ltr`）
- **部署**：Cloudflare Pages（纯静态文件）
- **广告**：Google AdSense，位置限定在「结果下方」和「页面底部」，绝不在结果上方或弹窗
- **无 JS 框架**：交互用 Vanilla JS，设计系统产出的组件需能用原生 HTML/CSS 实现

---

## 三、页面清单与功能需求

### 3.1 首页（`/`）

- 展示全部 23 个工具的入口卡片
- 工具按分类分组：日期类 / 健康类 / 财务类 / 教育与实用类
- 每张卡片包含：图标、工具名（阿语）、一句话描述
- 无搜索框、无筛选（工具总数不多，直接展示）
- 页面底部有广告位（1 个）

### 3.2 工具页（通用模板，复用于所有工具）

每个工具页结构固定，包含：

1. **面包屑导航**：首页 > 工具名
2. **标题区**：工具名（h1）+ 简短说明
3. **输入区**：表单控件（输入框、下拉、日期选择器等，按工具不同）
4. **计算按钮**
5. **结果区**：计算结果展示（数字结果需 LTR 方向）
6. **广告位**：结果下方 1 个
7. **相关工具推荐**：3–5 个内链卡片
8. **FAQ 折叠区**：5–8 个问答
9. **免责声明**：固定文字区块
10. **页面底部广告位**：1 个

**工具变体说明**（输入区会有差异）：

| 类型 | 示例工具 | 输入控件 |
|------|----------|----------|
| 单输入类 | 百分比、BMI | 1–3 个输入框 + 1 个按钮 |
| 双日期类 | 日期差、年龄 | 2 个日期选择器 |
| 多步骤类 | 孕期、排卵 | 日期 + 下拉选项 |
| 法规类 | VAT 六国 | 金额输入框 → 含税/不含税结果 |

### 3.3 法规工具国家选择页（如 `/vat/`）

- 展示六国卡片（国旗/名称），点击进入该国专属计算页
- 每国页复用「工具页通用模板」，标题和税率数据按国家不同

### 3.4 信任页（4 个，布局一致）

| 路径 | 阿语标题 | 内容 |
|------|----------|------|
| `/about/` | من نحن | 站点介绍、数据来源、方法论 |
| `/privacy/` | سياسة الخصوصية | 隐私政策、Cookie 说明、AdSense 声明 |
| `/contact/` | اتصل بنا | 联系邮箱 |
| `/terms/` | الشروط وإخلاء المسؤولية | 使用条款、免责声明 |

布局：标题 + 纯文字内容（prose），无广告，无交互控件。

### 3.5 全局组件

**导航栏（顶部）**：
- 站点 Logo/名称
- 导航链接：首页、关于我们
- 移动端汉堡菜单

**页脚**：
- 工具分类快捷链接
- 信任页链接（关于/隐私/联系/条款）
- 版权信息

## 四、核心交互模式

1. **即时计算**：用户输入完成后点按钮，结果区从隐藏变为显示（无页面跳转）
2. **错误提示**：输入无效时在输入框下方显示行内错误文字
3. **结果复制**：结果旁可选配复制按钮
4. **FAQ 折叠**：点击问题展开/收起答案（accordion）
5. **移动优先**：海湾用户主要使用手机访问，移动端体验优先

## 五、需要 Design 系统输出的文件

请输出以下内容，**不需要代码，只需视觉设计**。

### 5.1 设计系统基础（Design Tokens）

- 色彩系统：主色、辅助色、背景色、文字色、成功/警告/错误色

## 六、设计自由度说明

以下内容**完全由 Design 自由发挥**，不预设任何风格：

- 配色方案（深色/浅色/高饱和/低调均可）
- 卡片风格（扁平/有阴影/有边框均可）
- 图标风格（线性/填充/emoji 均可）
- 首页工具卡片排列方式（网格/列表均可）
- 是否使用渐变、插图、几何图形等装饰元素

**唯一硬约束：必须支持 RTL 布局。** 视觉稿需以阿拉伯语内容呈现（可使用占位文字，但需体现 RTL 文字方向，即文字从右向左排列，图标/箭头方向相应镜像）。

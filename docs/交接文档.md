## 1. 项目是什么

- **HijriTools / هجري**（hijritools.com）：阿拉伯语 **RTL** 在线工具站，面向**海湾六国**（沙特为主），靠 **Google 自然搜索引流**。
- **纯静态**（Astro SSG）→ **Cloudflare Pages**。无后端、无注册、所有计算在浏览器端完成、不收集用户数据。
- 已上线 **23 个工具**（日期/健康/财务/教育与实用）。
- **变现现状：广告已全部移除**（见 §11），当前无变现路径——是否恢复 AdSense 由 Owner 决定。

## 3. 架构与目录导览

```
src/
  data/        ← 事实数据(单一来源)：tools.js(工具元数据) countries.js vat.js
               hijri-holidays.js gender-chart.js icons.js(工具→图标id)
  lib/         ← 纯函数计算(每个工具一个文件) + hijri.js date-utils.js seo.js(JSON-LD)
  layouts/     ← ToolLayout.astro(唯一布局，注入 SEO/字体/页眉页脚/分享条)
  components/  ← SiteHeader SiteFooter ShareButtons(全局浮动) Faq Icon
               RelatedTools CountrySwitcher Disclaimer
  pages/       ← 每工具一个 <slug>/index.astro；动态路由 vat/[country].astro、calendar/[hy].astro
               信任页 about/privacy/contact/terms.astro；sitemap.xml.js(自定义端点)
  styles/      ← tokens.css(设计令牌单一来源) global.css fonts.css
public/        ← fonts/ sprite.svg(线性图标雪碧图，外链复用) og.png favicon.svg robots.txt _headers
tests/         ← Vitest，对应 src/lib/*
docs/          ← 设计/计划/改动清单/本交接文档
```

**核心心智模型**：
- **数据(`src/data/`) vs 算法(`src/lib/`) 分离**。法规变化只改 data；算法在 lib。
- **工具元数据单一来源 = `src/data/tools.js`**。导航、首页卡片、相关链接、sitemap 全部从它派生。
- **设计令牌单一来源 = `src/styles/tokens.css`**。改一个变量全站换肤；组件零改动。
- **新增国家** = countries.js 加一条 + 对应工具 data 补该国值；法规页 `getStaticPaths` 自动生成、sitemap 自动包含。

## 4. 必守铁律（违反会出事）

1. **计算逻辑 TDD**：函数写 `src/lib/<tool>.js` 纯函数。**先写测试 RED → 再实现 GREEN**。Owner 无法校对计算正确性，**测试是唯一保证**。改动后 `npm test` 必须全绿。
2. **阿语内容必须过审**：Owner **不懂阿拉伯语**，无法校对。任何新增/改动的阿语文案（标题/描述/FAQ/UI/免责）**必须经 `arabic-content-reviewer` 子代理审校**——这是阿语正确性的唯一防线。本项目历次审校已抓出多处错误（见 `docs/改版改动清单-2026-06.md`）。
3. **伊历时区陷阱**（最易翻车）：`@umalqura/core` 内部按**本地时区**工作；`src/lib/hijri.js` 已通过「整数 y/m/d 交换」消除时区依赖（`uqFromGregorian`/`uqDateToUtc`）。**绝不要直接用库的 `.date` Date 对象**，否则 UTC 构建机上差 1 天。锚点：`1447-01-01 = 2025-06-26`。**改 hijri.js 后必跑 `tests/hijri.test.js`**。
4. **SEO 每页必备**：`<html lang="ar" dir="rtl">`、唯一 h1、title、meta description、canonical、hreflang(ar/x-default)、JSON-LD（WebApplication，含 FAQ 加 FAQPage，工具页自动加 BreadcrumbList）。由 `ToolLayout.astro` + `lib/seo.js` 统一注入。内链 ≥3（`RelatedTools`）。免责声明必挂（`Disclaimer`）。
5. **RTL**：CSS 一律**逻辑属性**（`margin-inline-start`/`inset-inline` 等）；数字/计算结果用 `.num`（`dir:ltr; unicode-bidi:isolate`）防错乱。**例外**：全局浮动分享条用**物理 `left:0`**（设计要求固定在屏幕左侧），不是逻辑属性——这是有意为之。

## 5. 关键技术坑（除铁律外）

- **Astro `<script>` 不要配 `define:vars` + `import`**：define:vars 会把脚本降级为内联非模块脚本，`import` 静默失败。传服务端值用 `data-*` 属性（见 `vat/[country].astro`、`contact.astro`）。
- **图标**：`<Icon id="ico-x">` → `<use href="/sprite.svg#ico-x">`，sprite 是**外链文件** `public/sprite.svg`（每页省体积、可缓存）。加新图标要同时改 `public/sprite.svg` 和 `src/data/icons.js`。`currentColor` 对外链 use 在现代浏览器正常。
- **字体**：自托管 woff2 + `unicode-range` 子集，`ToolLayout` 里 preload `ibmplex-400-arabic` + `reemkufi-arabic`。换字体要同步 `fonts.css` + preload + `tokens.css` 的 `--font-base`/`--font-display`。
- **年历是动态路由**：`calendar/[hy].astro` 的 `getStaticPaths` 硬编码年份列表（当前 1447/1448/1449），内容全自动生成。`tools.js` 的 calendar 条目 `href` 决定首页卡指向哪年、`staticPaths` 决定 sitemap 收哪些年。

## 6. 新工具开发流程

1. `src/data/tools.js` 加元数据（含 `category`、`related`、`updated`、阿语 `titleAr/shortAr/descAr`）。
2. `tests/<tool>.test.js` 写测试 → `npm test` 确认 **RED**。
3. `src/lib/<tool>.js` 实现纯函数 → **GREEN**。
4. `src/data/icons.js` 给该工具映射一个 `ico-*`（必要时在 `public/sprite.svg` 加新图标）。
5. `src/pages/<slug>/index.astro`：用 `ToolLayout` + `tool-head`(图标芯片标题) + 输入区 + 结果区 + `Disclaimer` + `Faq` + `RelatedTools`；交互写页面底部 `<script>`（被打包为 module，可 import lib）。
6. **阿语文案过 `arabic-content-reviewer`**。
7. `npm run build` 验证 + `tool-page-auditor` 子代理对照铁律抽查。

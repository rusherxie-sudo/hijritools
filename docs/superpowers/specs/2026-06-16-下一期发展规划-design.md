# HijriTools 下一期发展规划(已执行)

> 制定 + 执行:2026-06-16。关联:`docs/2026-06-14-后续开发计划.md`(原四阶段全景)、`CLAUDE.md`(项目宪法)。

## 一、策略定位

站点上线约 2 天、流量≈0、处于 Google 收录期。**结论:趁收录期用「零/低验证风险 + 高复用 + 高信号」工具快速铺量**,把页面数与权重做起来;变现(AdSense)与需数据/内容站推后。

经与 Owner 确认的两个方向决策:
1. **首要目标 = 铺量抢收录期**(而非提升变现 / 扩市场 / 深耕护城河)。
2. **范围 = 阶段一收口 + 第二波**(共约 12 个工具)。

## 二、已交付(工具数 11 → 22 上线)

全部:Vanilla JS 纯函数 + Vitest TDD(独立锚点)+ ToolLayout 页面(SEO/RTL/JSON-LD/面包屑/GA4 自动注入)+ health/calc Disclaimer + 3 条阿语 FAQ + 内链≥3。经 `arabic-content-reviewer` 审校并修正(口语疑问词、性别一致、东阿拉伯数字、emoji 等)。

### Wave 1 — 阶段一收口(健康簇共享 `src/lib/health.js` + 房贷)
- `ideal-weight` 理想体重(Devine/Hamwi)
- `bmi` 身体质量指数(WHO 分级)
- `body-fat` 体脂率(美国海军公式)
- `calories` 每日热量 TDEE(Mifflin-St Jeor)
- `water` 每日饮水量
- `mortgage` 房贷/融资月供(等额本息;伊斯兰金融话术 التمويل/نسبة الربح)

### Wave 2 — 第二波
- `countdown` 斋月/开斋节倒计时(伊历护城河)
- `discount` 折扣计算器
- `unit-convert` 单位换算(长/重/温)
- `period` 月经周期计算器
- `weighted` 加权百分比(沙特大学录取النسبة الموزونة)

## 三、暂缓:tafqit(تفقيط الأرقام,数字→阿拉伯文字)

代码与测试已完成并入库,但 **`live:false`(不进导航/sitemap)**。原因:阿拉伯语「数-名一致(تمييز)」语法复杂(2→双数 ريالان、3-10→复数 ريالات、200000→مئتا ألف、各货币双数/复数形态各异),`arabic-content-reviewer` 发现多处真实语法错误。一个金额大写工具若把常见小额写错会损害可信度,而 Owner 无法校对阿语。**需专门的 تمييز 语法引擎 + 母语审校后再上线。**

## 四、明确不做(收录期纪律)

暂不碰:阶段二需数据工具(交通违章)、阶段三天课/劳工赔偿、阶段四内容库(名字含义/梦境)、国家扩张。理由:无权重时性价比低或引入无法校对的内容风险。等流量/权重起来再说。

## 五、度量门

Wave 上线满 2-3 周后,用 GSC(曝光/查询/收录)+ GA4(行为)实际数据复盘:哪些词开始有曝光、哪些工具留得住人,据此决定下一批 + 是否提前启动变现。
